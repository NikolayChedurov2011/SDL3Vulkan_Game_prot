# SDL3Vulkan_Game_prot
Game that use the "Engine prototype". Playground to learn and implement tech stack, patterns etc. 

## Installation and build:

`git clone -b develop https://github.com/NikolayChedurov2011/SDL3Vulkan_Game_prot.git --recurse-submodules`

`cd SDL3Vulkan_Game_prot`

`mkdir build`

`cd build`

Depends on your default generator and the need for a solution
`cmake -G "Visual Studio 17 2022" ..`     or    `cmake ..`
